Demo Target Form

This simulates an external form (e.g. CATC registration). Use it to test the bookmarklet autofill workflow.
To set up: create a field map in the Protocol Engine with the CSS selectors shown below, stage your case, then click the bookmarklet on this page.

CSS selectors for this form:
patient → #patientName   dob → #patientDOB   caller → #callerName   callback → #callbackNumber   facility → #sendingFacility   acuity → #acuityLevel   location → #patientLocation   case_id → #caseIdField

Desktop RPA Guide

If the target system is a desktop application (not a web page), you can use the exported case JSON with a desktop automation tool. Two free options:

Power Automate Desktop (Windows, free)

  1. Click Export to save the case as a JSON file.
  2. In Power Automate Desktop, create a flow that reads the JSON file.
  3. Use Read text from file + Convert JSON to custom object to parse the fields.
  4. Use Populate text field in window to type each value into the target app's fields.
# Power Automate Desktop pseudo-flow:
File.ReadText File: %ExportPath% → %JsonText%
Variables.ConvertJsonToCustomObject Json: %JsonText% → %Case%
UIAutomation.PopulateTextField TextField: 'Patient Name' Text: %Case.patient%
UIAutomation.PopulateTextField TextField: 'DOB' Text: %Case.dob%
UIAutomation.PopulateTextField TextField: 'Callback' Text: %Case.callback%

AutoHotkey v2 (Windows, free)

Export the case JSON, then run an AHK script that reads it and types into the active window:

#Requires AutoHotkey v2.0
caseFile := FileRead("case-export.json")
caseData := Jxon_Load(&caseFile)

; Focus the target app, then Tab to each field and type
WinActivate "CATC"
Send caseData["patient"] "{Tab}"
Send caseData["dob"] "{Tab}"
Send caseData["callback"] "{Tab}"

Both approaches read the same exported JSON that the Export button produces — no API key or network access needed.
